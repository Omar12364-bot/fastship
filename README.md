# 📦 FastShip Express

نظام إدارة الشحن والتوصيل — لوحة تحكم متكاملة باللغة العربية.

## 🗂️ هيكل المشروع (GitHub Pages Compatible)

```
fastship-express/
├── login.html      ← صفحة تسجيل الدخول
├── index.html      ← لوحة التحكم الرئيسية
├── style.css       ← كل الـ styles + print styles
├── app.js          ← كل الـ logic والبيانات
└── README.md
```

> **ملاحظة:** كل الملفات في نفس المجلد لتعمل على GitHub Pages بدون مشاكل.

## 🚀 تشغيل المشروع

```
افتح login.html في المتصفح
```
لا يحتاج server أو installation — فقط browser.

## 📌 GitHub Pages

```
1. ارفع الملفات على GitHub repository
2. اذهب لـ Settings > Pages
3. اختر branch: main, folder: / (root)
4. Site URL: https://username.github.io/repo-name/login.html
```
